# Poppins font asset

The Poppins Latin subset is self-hosted for the Create Order workspace at the
weights used by the existing stylesheet: 400, 500, 600, and 700. Existing
Arabic system-font fallbacks remain responsible for Arabic glyphs.

Poppins is licensed under the SIL Open Font License 1.1. The license text is
included in `OFL-Poppins.txt`; the font files were obtained from the Google
Fonts Poppins distribution and are kept unchanged.
